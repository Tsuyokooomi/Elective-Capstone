# VPN Setup on Windows
SOP ID: KB-007
Category: Network and Email
Applies to: Employees with a CapstoneCompany Windows laptop who work outside the office.
Action: None
Escalation: If the install is blocked.

Before you start: You need MFA set up (see KB-003) and an internet connection.

Steps:
1. Open Software Center and install "CapstoneVPN".
2. Open CapstoneVPN.
3. Enter the server address: vpn.capstonecompany.example.
4. Sign in with your work email and password.
5. Approve the MFA prompt.
6. Wait for the status to show Connected.
7. Test by opening the intranet at intranet.capstonecompany.example.

Notes:
- Disconnect from the VPN when you finish work.
- Personal devices cannot use the company VPN.

Escalate to a human if: CapstoneVPN is missing from Software Center, or the install fails.

Related SOPs: KB-003, KB-008
