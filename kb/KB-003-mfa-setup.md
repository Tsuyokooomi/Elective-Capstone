# Multi-Factor Authentication (MFA) Setup
SOP ID: KB-003
Category: Accounts and Access
Applies to: All CapstoneCompany employees. MFA is required for every account.
Action: None
Escalation: If setup fails.

Steps:
1. Install an authenticator app on your phone (Microsoft Authenticator or Google Authenticator).
2. Sign in to selfservice.capstonecompany.example on your computer.
3. Go to Security, then Add sign-in method, then Authenticator app.
4. Scan the QR code with the app.
5. Enter the 6-digit code from the app to confirm.
6. Save your backup codes in a safe place, such as a locked note in your password manager. Do not save them in your email.

Notes:
- Codes change every 30 seconds. If a code fails, wait for the next one.
- Check that your phone's clock is set to automatic time. A wrong clock makes codes fail.
- Never share a code with anyone, including IT staff.

Escalate to a human if: the QR code does not load, or codes fail after you fix the phone clock.
