# Software Installation Request
SOP ID: KB-012
Category: Devices and Software
Applies to: Installing programs on a CapstoneCompany device.
Action: create_ticket for non-catalog software
Escalation: For software outside the catalog.

Approved software (in the catalog):
1. Open Software Center on your laptop.
2. Select the program and select Install.
3. Wait for the install to finish. Restart if asked.

Software outside the catalog:
1. Submit a ticket with the software name, the vendor website, and the business reason.
2. Your manager approves the request.
3. The security team reviews the software. Review takes up to 5 business days.
4. If approved, IT installs it for you.

Rules:
- Employees do not receive local administrator rights.
- Personal or unlicensed software is not allowed on company devices.

Escalate to a human if: Software Center shows an error, or the program you need is blocked.
