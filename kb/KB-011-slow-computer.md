# Slow Computer
SOP ID: KB-011
Category: Devices and Software
Applies to: CapstoneCompany laptops and desktops.
Action: None
Escalation: If the cause is not clear after the steps.

Steps:
1. Save your work and restart the computer. Restart at least once a week.
2. Close apps and browser tabs that you do not use.
3. Open Task Manager (Ctrl+Shift+Esc). Sort by CPU and Memory. Note any app that uses most of the resources, and close it if it is safe to do so.
4. Check free disk space. Keep at least 10% free. Run Disk Cleanup if it is low.
5. Install pending Windows updates.
6. Check that the laptop is plugged in and set to the Balanced power plan.

Escalate to a human if: the computer is still slow after these steps, the fan runs loud all the time, or the laptop gets very hot. If you also see pop-ups or unknown programs, follow KB-018 for possible malware.
