# Software Access Request
SOP ID: KB-005
Category: Accounts and Access
Applies to: Requests for an account or licence on approved CapstoneCompany software, such as Jira, Figma, or Adobe Acrobat.
Action: create_ticket
Escalation: If the software is not in the catalog.

Steps:
1. Check that the software is in the Software Catalog on selfservice.capstonecompany.example.
2. Submit an access request with the software name, the access level you need, and a short business reason.
3. The system sends the request to your manager for approval. Managers should respond within 2 business days.
4. After approval, IT assigns the licence. You get an email when it is ready.
5. Sign in to the software, or install it from Software Center (see KB-012).

Notes:
- The helpdesk assistant can open this ticket for you. It needs the software name and the reason.
- Access without manager approval is not granted.

Escalate to a human if: the software is not in the catalog, or the request is urgent and your manager is away.

Related SOPs: KB-006, KB-012
